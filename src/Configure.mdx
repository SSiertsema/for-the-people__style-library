## Nice! Hoe kan ik er gebruik van maken?

Jazeker! Op verschillende manieren

### Inladen CSS van CDN

1. Inladen CSS in je website
2. HTML kopieren uit component documentatie

```html
<html lang="en">
<link>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Sample PZH CSS library usage</title>
    <link rel="stylesheet" href="URL NOG TOEVOEGEN"></link>
</head>
<body>
    <button class="button-primary button-primary--size-medium">
        <span>Button Primary</span>
      </button>
</body>
</html>
```

**Let op:** Houd er rekening mee dat je applicatie beveiligd kan zijn met een CSP (Content security policy). In dat geval kan het mogelijk zijn dat de applicatie het CSS bestand niet in mag laden.

### Gebruik maken van SCSS library

We stellen SCSS variabelen beschikbaar via NPM package @pzh-temporary/html-componenten-library.

1. Vanuit een npm applicatie command line:

```JS
npm i -D @pzh-temporary/style-library
```

2. In scss bestand:

```SCSS
@import '@pzh-temporary/style-library/variables/colors.scss';
div {
    background-color: $color-green-500;
}
```
